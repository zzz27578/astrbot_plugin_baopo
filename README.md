# 爆破

是否烦恼bot无法自己reset清理上下文？是否bot报错需要重置可是舍不得上下文？是否需要bot定时清理自己焕然一新？那就快来试试爆破！推荐与小窝插件配合使用，写完日记睡大觉，每天消耗降低，回忆不减。

爆破是一个 AstrBot 上下文换房插件。它会先让模型总结当前会话，再创建新会话，把前情提要作为隐藏系统备忘注入进去，最后按配置清理旧上下文。

## 功能

- 注册工具 `perform_memory_transfer`
- 提供命令 `/sl` 立即爆破
- 支持当前模型自动总结上下文
- 支持备用总结模型
- 支持隐藏注入工具调用规范
- 支持安装 `context-cutover` skill，让 bot 学会正确使用爆破工具
- 支持绑定会话后的定时爆破

## 指令

`/sl`：立即总结当前上下文并换房。

`/sl bind`：绑定当前会话，用于定时爆破。

`/sl status`：查看爆破状态。

`/sl skill`：安装并启用爆破 skills。

## 配置建议

推荐保持“工具调用需要明确确认”开启。这样 bot 不会因为话题结束、任务完成等主观判断自行爆破。

如果需要凌晨自动换房，可以打开“启用定时爆破”，填写时间，例如 `03:00`，然后在目标会话发送 `/sl bind`。

更推荐的高级方式是让 bot 自己创建定时任务，并在任务里先完成日记写入，再调用 `perform_memory_transfer`。

## 工作方式

1. 读取当前会话历史。
2. 使用当前模型总结上下文。
3. 当前模型失败时，尝试备用总结模型。
4. 新建 AstrBot conversation。
5. 把总结作为“系统自动提示词”注入新会话。
6. 删除旧 conversation，完成上下文清理。

这不是无损搬运全部上下文，而是“总结迁移”。总结质量越高，换房后的接续越自然。

## 与小窝插件的配合

推荐让 bot 自主创建定时任务：每天先调用小窝写入日记，再调用爆破进行睡大觉。这样可以做到“物理日记持久化 + 上下文清理 + 新窗口接续”。
