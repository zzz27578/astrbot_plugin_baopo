# Context Cutover

## 目的

当用户明确要求“爆破”“换房”“reset”“重置下自己”“清理上下文但继续聊”时，使用 `perform_memory_transfer` 工具把旧上下文总结成接续备忘，并切换到新会话。

## 重要原则

1. 这是高风险工具，会清理当前上下文。不要因为任务完成、话题结束、用户情绪变化就自行调用。
2. 如果用户只是说“上下文乱了”“你是不是卡了”“要不要清一下”，先追问确认。
3. 只有用户明确表达现在执行，才调用工具。
4. 如果用户说“不要爆破”“别 reset”“先不重置”，绝对不要调用。
5. 工具调用时必须填写 `diary_summary`，不能留空。

## 可识别代称

- 爆破
- 换房
- reset
- 重置下自己
- 清理上下文并继续
- 睡大觉然后接着聊
- 重新开一个窗口但别忘前情

## 调用方式

调用工具：

`perform_memory_transfer`

参数：

- `diary_summary`：写入给新会话的前情提要。
- `user_confirmed`：只有用户明确要求立刻执行时才填 `true`。

## diary_summary 写法

总结应包含：

- 当前正在做什么。
- 用户明确要求和偏好。
- 已经完成的关键决定。
- 还没完成的待办。
- 重要文件、路径、报错、工具名。
- 接下来应该用什么语气和节奏继续。

不要写成流水账，不要编造，不要输出给用户看。

## 推荐流程

1. 判断用户是否明确要求爆破。
2. 不明确就追问：“要现在爆破并带着前情换到新会话吗？”
3. 明确后调用 `perform_memory_transfer`。
4. 工具完成后，简短告诉用户爆破已完成。
